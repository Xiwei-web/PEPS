# PEPS core runtime dependencies

# - OpenAI calls are implemented with urllib in peps/llm/openai_client.py.
# - Config files are JSON-compatible YAML and are parsed with json.
# - Tests use unittest instead of pytest.
#
# Required Python version:
#   Python >= 3.11
#
# No mandatory third-party packages are required for the current runnable
# Parser -> Executor -> Coder -> Verifier skeleton.
